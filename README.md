# ✅ Habit Tracker

A mobile-first daily habit tracker. No account or login needed — data saves privately on your device.

## Features
- ☀️ Daily check-in with checkbox + optional notes for each habit
- 📊 Progress page with streaks, weekly grid, 30-day heatmap, and notes log
- ⚙️ Add, rename, reorder, and delete habits with custom emoji and color
- 🔔 Daily reminder notifications (browser-based)
- 📱 Designed for iPhone/Android mobile browsers

## Default Habits
- 💪 Work Out
- 🥗 Eat Healthy
- 📚 Read
- ❤️ Family Time

## Setup & Deploy

### Run locally
```bash
npm install
npm run dev
```

### Deploy to GitHub Pages
1. Create a new GitHub repo
2. Edit `vite.config.js` — update `base` to your repo name
3. Push code and run:
```bash
npm run deploy
```
4. Enable GitHub Pages: repo → Settings → Pages → Branch: gh-pages

## Tips
- Add to home screen on iPhone: tap Share → "Add to Home Screen" for an app-like experience
- Data is stored in your browser's localStorage — clearing browser data will erase logs
- To back up, use the browser on the same device consistently
